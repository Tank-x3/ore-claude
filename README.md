# おれのClaude、おまえのClaude

Claude Code設定バトル — あなたのClaude Codeの設定はどれだけイケてる？

## インストール

```
/plugin marketplace add mii012345/ore-claude
/plugin install ore-claude@mii012345-ore-claude
```

## 使い方

Claudeに話しかけるだけ:

```
おれのClaude、スコアリングして
```

または `/score` スラッシュコマンドを使用。

## スコアリングの仕組み

| カテゴリ | 配点 | 内容 |
|---------|------|------|
| 構造スコア | 50pt | CLAUDE.md / hooks / plugins / memory / skills / settings |
| 活用スコア | 30pt | 継続利用日数 / 機能活用幅 / Claudeコミット / チーム・タスク |
| Claude評論 | 20pt | 設計思想の一貫性 / 独創性（Claudeが自分で採点） |

設定の中身は一切外部に送信されません。構造メタデータ（行数・ファイル数・種別）のみを集計します。
